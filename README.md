# sound-playground-demo
Interactive musical instrument prototype for SOUND PLAYGROUND, Karlsruhe 2027.

**Interactive digital sketch, not the installation.** Four stations (PULSE, BREATH, RESONANCE, MOVEMENT),
each with one pad and one rotary dial, play one shared composition while a schematic Palace responds.
Sound is synthesised in the browser (Web Audio). The Palace image is a simplified schematic, not
projection-mapping geometry and not a Notch render. Nothing is uploaded; recordings stay on the visitor's device.

- `index.html`: current version, browser sketch 0.2 (shared tempo and D-minor harmony, rotary dials,
  multitouch, no stuck notes, limiter, 30 s / 3 min recording with a gesture log)
- `v0.1.html`: the first version, kept for comparison

Play: open the page, press **Enable sound** (or any pad), and hold the pads; keys 1–4 also work.
